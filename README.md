# Jiggle Puppet

Upload an image, drop jiggle pins on the squishy parts (like After Effects' puppet tool), then drag, throw and poke it. Spring physics does the rest.

- Jiggle pins (pink) with per-pin radius, wobble speed, bounciness and left/right/up/down travel limits
- Anchor pins (yellow) keep areas rigid
- Peel tool: lift the image off like a sticker or tattoo stencil, with backing paper, curl shading, shadow, and stencil ink (or a faded copy) left behind. Release to stick back, stay lifted, or peel off
- Canvas presets: Instagram Reel 9:16 (1080×1920), 4:5, 1:1, 16:9, custom
- Record a take, then export a PNG sequence with alpha (zip or folder), WebM with alpha, or MP4
- Reference background for lining things up; it's never exported

Single static `index.html` (three.js from CDN). Open it in Chrome for the best export support.
